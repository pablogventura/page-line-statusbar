# Foja para LibreOffice Writer

Extension para Writer: numeros a letras y barra de estado `Pag N - Lin M`.

## Instalar

```bash
./scripts/build_oxt.sh
```

En LibreOffice: **Herramientas > Administrador de extensiones > Anadir** y elegi `dist/foja.oxt`. Reinicia Writer.

## Uso

- Menu / toolbar **Foja**: **De N a Letras** (selecciona un numero y convierte a texto)
- Barra de estado: `Pag N - Lin M`

Manual completo: [MANUAL.md](MANUAL.md).

## Actualizar

**Herramientas > Administrador de extensiones > Buscar actualizaciones**
